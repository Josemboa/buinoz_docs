## Criar e editar clientes

Para criar clientes clique no menu “Clientes” e de seguida no botão flutuante verde
e uma nova tela será aberta.
Ao clicar em um item da lista uma nova tela irá aparecer com os detalhes do cliente
criado, onde poderá editar os dados do cliente.
Para criar ou editar clientes preencha todos os campos e clique em criar ou
actualizar.

## Criar e editar fornecedores

Para criar fornecedores clique no menu "Fornecedores" e de seguida no botão flutuante verde
e uma nova tela será aberta.
Ao clicar em um item da lista uma nova tela irá aparecer com os detalhes do fornecedor
criado, onde poderá editar os dados do fornecedor.
Para criar ou editar fornecedores preencha todos os campos e clique em criar ou actualizar.
