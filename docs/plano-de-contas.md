# Plano de contas oficial (PGC-NIRF)

[Descarregar o plano de contas em PDF](/pdf/buinoz-plano-de-contas.pdf)

Esta é a lista das **488 contas** do plano oficial de Moçambique que o Buinoz traz de origem: o PGC-NIRF, aprovado pelo **Decreto n.º 70/2009, de 22 de Dezembro**. Todas as lojas vêem estas contas em **CBL27 - Plano de Contas**.

- As contas desta lista são **globais**: são iguais para todas as lojas e não se apagam.
- Cada loja pode criar **sub-contas** próprias por baixo de uma conta oficial (ex.: 1211 Banco BIM, por baixo de 121). Veja como em [Manual do contabilista](/manual-contabilista#plano).
- O Buinoz acrescenta 3 contas que não estão no decreto: **111 Caixa Geral**, **511 Capital Subscrito** e **91 Garantias Prestadas**.
- A classe 9 (contas de ordem) não tem contas no decreto. Fica livre para a empresa.
